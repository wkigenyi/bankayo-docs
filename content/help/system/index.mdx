---
title: System
description: Institution-wide tools that are not organization or product settings.
---

Open **System** in the sidebar (a navigation group, not a page) or press
**Ctrl+K** and type "system". You need report-reading, configuration, code, permission,
scheduler, audit, hook, external-service, data-table, entity-mapping, or external-event permission — if the group is missing, ask your
administrator.

System lists institution-wide tools that are not organization or product
settings. Open a screen from the group (or press **Ctrl+K** and type its name).
[Manage reports](/help/system/reports) is live: create custom reports, copy
a core report when you need to change its SQL, and choose which reports
appear in the [Reports](/help/reports) catalog.

[Configurations](/help/system/configurations) is live: view and update global
enable/disable flags and institution-wide values.

[Codes](/help/system/codes) is live: manage Fineract lookup codes and their
dropdown values.

[Maker-checker](/help/system/maker-checker) is live: choose which commands
need a checker before they take effect (institution-wide, not per role).

[Jobs](/help/system/jobs) is live: view scheduler jobs, start or stop the
scheduler, run jobs on demand (with optional parameters), configure
close-of-business steps, and watch loan COB catch-up.

[Audit trails](/help/system/audits) is live: read-only history with filters,
detail sidebar, and CSV/Excel export.

[Hooks](/help/system/hooks) is live: send Fineract events to a URL or SMS
gateway. Create and edit use a four-step wizard. Templates and config fields
come from Fineract.

[External services](/help/system/external-services) is live: SMS, email,
Amazon S3, and notification gateways on a side-tab settings page you view
and edit in place.

[Manage data tables](/help/system/datatables) is live: define extra fields on
clients, groups, loans, and other records. That admin screen is not the Extra
data tab on a client, group, or center — those tabs fill values on a record.

[System information](/help/system/information) is live: build, server, tenant,
and signed-in staff facts. Fineract has no license API.

[Entity-to-entity mapping](/help/system/entity-mapping) is live: restrict which
offices or roles can use which loan products, savings products, or charges.

[External events](/help/system/external-events) is live: enable or disable
which outbound business-event types Fineract posts to Kafka or JMS.
That is not Hooks and not the notifications bell.

[Account number preferences](/help/system/account-number-preferences) is live:
one prefix format per entity (client, loan, savings, center, group, shares,
working capital loan). Sequential versus random numbers is a configuration
flag, not that screen.

Other System screens are still pending.
