This is step 1 of the [create wizard](/help/products/savings/create). After
save, the same fields appear under **General** on the product.

## Identity

- **Name** — up to 100 characters. This is what officers see when they open a
  savings account. Keep it distinct from other savings products (for example
  “Voluntary savings” versus “Compulsory savings”).
- **Short name** — at most **four** characters. The core banking system uses
  it as a compact code on lists and reports; keep it unique enough to
  recognise (for example `VS` or `COMP`).
- **Description** — optional, up to 500 characters. Use it for notes that
  officers should see on the product, not for fields that belong later
  (rates, balances, and GL accounts have their own steps).

## What is not on this step

Savings products have **no** start or close date, **no** external ID on the
product itself, and **no** organization fund. If you need an availability
window or a fund label, those exist only on
[loan products](/help/products/loans/details). An officer can still set an
optional external ID when they
[open a savings account](/help/clients#opening-an-account).
