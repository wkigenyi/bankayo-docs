title: Password preferences
description: Choose which seeded Fineract policy new user passwords must meet.
---

Open **Password preferences** in Organization (or press **Ctrl+K** and
type "password preferences"). You need **READ_PASSWORD_PREFERENCES** to
open the screen and **UPDATE_PASSWORD_PREFERENCES** to save.

This is Fineract `GET /passwordpreferences/template` and
`PUT /passwordpreferences`. Policies are seeded (`simple`, `secure`, and
often `strong`). Fineract has no API to create a new policy.

## What you can do

Pick one policy and **Save**. The rule text on each card is Fineract’s
description. Bankayo labels known keys (Simple, Standard, Strong); any
other key uses the Fineract key.

The change applies the next time a user password is set or reset. It does
not rewrite existing passwords.

This is not the Users screen (where you set a person’s password) and not
two-factor authentication.
